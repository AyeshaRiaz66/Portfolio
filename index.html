AI / ML Fintech

Fraud Detection Website

A web-based system that flags suspicious financial transactions using machine learning on real transaction data.

Problem

Existing fraud detection on the transaction dataset was missing genuine fraud cases — in fraud detection, a missed case (false negative) is far costlier than a false alarm.

Approach

Applied XGBoost and Support Vector Machine (SVM) to the existing dataset, prioritizing recall alongside accuracy so fewer real fraud cases slipped through.

Outcome

Improved both recall and accuracy over the baseline dataset performance, delivered as a working website interface.

Face Mood Detector

An Android app that reads facial expressions and recommends activities suited to the user's detected mood.

Problem

Mood- and wellness-tracking apps usually rely on the user manually logging how they feel, which people quickly stop doing.

Approach

Used the Google Vision API for facial emotion detection inside a native Kotlin Android app, turning mood-logging into a passive, camera-based interaction instead of manual entry.

Outcome

App detects mood automatically and returns personalized activity recommendations based on the result.
